# C Kütüphane Yönetim Sistemi

Bu proje, C programlama dilinde `struct` yapıları ve File I/O (Dosya Okuma/Yazma) işlemleri kullanılarak geliştirilmiş terminal tabanlı bir kütüphane yönetim otomasyonudur. 

## 🚀 Teknolojiler
- C Programlama Dili
- File I/O (Veri Kalıcılığı)
- Pointers & Structs

## ⚙️ Özellikler
- Yeni kitap ekleme ve `kutuphane_veritabani.txt` dosyasına kaydetme.
- Mevcut envanteri txt dosyasından okuyarak terminalde listeleme.
- Bellek yönetimi prensiplerine uygun kod yapısı.
